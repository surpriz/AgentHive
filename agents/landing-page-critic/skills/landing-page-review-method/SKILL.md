# Landing page review method

## The visitor's question

Every page is read with one question: "is this for me, and does it do what I came for?" Write
it in the audience's words before reviewing. A Google-ad visitor wants the thing they searched;
a referral visitor wants to confirm what their colleague said; a cold-social visitor needs a
reason to stay.

## Above-the-fold test

In the first screen, within five seconds, the visitor must be able to say: what it is, for whom,
what it does for them, and what to click. Missing any one of these is a high-impact problem,
regardless of how good the sections below are.

## Problem classes

| Class | Symptom | Fix pattern |
|---|---|---|
| unclear | abstract nouns, category words, no object | name the job and the user |
| unproven | claims without number, name or mechanism | add the number you have, or the mechanism, or cut the claim |
| irrelevant | the page talks about something the visitor did not come for | match the source (ad, search term) in the first line |
| buried | the right line exists below the fold | move it up |
| weak ask | CTA is generic, or asks for too much too early | state what happens next; reduce the step |
| generic | the copy fits any competitor | add what only this product does, in concrete terms |

## Ranking

Impact: headline and first screen > first CTA > proof > sections > FAQ > footer. Within a block,
problems affecting every visitor beat problems affecting a segment. Effort: a line rewrite is
minutes; a new proof block is an hour; new proof you must collect is a day.

## Proof standards

Specific beats big: "Invoices paid in 9 days instead of 31 at Maison Loup" beats "trusted by
500+ companies". A logo wall is proof only if the visitor knows the logos. A testimonial needs a
name, a role and a result. No proof is better than vague proof; vague proof trains the visitor to
distrust the rest.

## CTA rules

- Says what happens next and how long it takes.
- One primary action per screen; a secondary action is allowed if it is clearly smaller.
- The first CTA appears in the first screen and again after the proof.
- No "Get started", "Learn more", "Submit".

## Rewriting

Use the audience's vocabulary (the words in the ad, the search term, the job title's jargon).
Outcome first, mechanism second, number third. Short sentences. Delete: all-in-one, modern,
streamline, unlock, seamless, powerful, cutting-edge, revolutionary, next-generation,
empower, elevate. No "it's not X, it's Y". No triads for rhythm.
